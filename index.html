<> 01 / STRUKTUR index.html

HTML adalah kerangka halaman.

HTML memberi tahu browser apa isi halamanmu: judul, paragraf, gambar, tombol, dan bagian lainnya. File index.html biasanya menjadi halaman pertama yang dibuka browser.

Tag ditulis berpasangan: ada tag pembuka dan penutup. Isi halaman yang terlihat pengunjung diletakkan di antara <body> dan </body>.

  • <h1> untuk judul utama.
  • <p> untuk paragraf.
  • <button> untuk tombol yang bisa ditekan.
Contoh HTML
<h1>Halo, dunia!</h1>
<p>Ini website pertamaku.</p>
<button>Klik aku</button>
HASILNYA
Halo, dunia!

Ini website pertamaku.

LATIHAN 01

Buat kartu perkenalan

Tambahkan judul, paragraf tentang dirimu, dan satu tombol ke dalam HTML.

Petunjuk

Gunakan <h1> untuk nama, <p> untuk cerita singkat, dan <button> untuk tombol.

Contoh jawaban 
<main>
  <h1>Halo, aku Rani!</h1>
  <p>Aku sedang belajar membuat web.</p>
  <button>Kenalan yuk</button>
</main>
# 02 / TAMPILAN style.css

CSS membuat halaman tampil menarik.

CSS mengatur warna, ukuran tulisan, jarak, dan tata letak. Kita memilih elemen HTML menggunakan selector, lalu memberi aturan di dalam kurung kurawal.

Contoh di samping memilih semua elemen <h1>, mengubah warnanya, dan memberi jarak di bawah judul.

  • color mengubah warna teks.
  • background mengatur latar.
  • margin mengatur jarak di luar elemen.
Contoh CSS
h1 {
  color: #7866cb;
  margin-bottom: 12px;
}
HASILNYA
Judul jadi berwarna!

Atur tampilan sesukamu dengan CSS.

LATIHAN 02

Beri gaya pada kartu

Ubah warna latar, warna judul, dan sudut kartu agar tampil lebih menarik.

Petunjuk

Mulai dengan selector body, lalu atur background, color, dan border-radius.

Contoh jawaban 
body {
  background: #f3e8ff;
  color: #4c326b;
}

.card {
  padding: 24px;
  border-radius: 16px;
}
JS 03 / INTERAKSI script.js

JavaScript membuat halaman bereaksi.

JavaScript menambahkan perilaku pada halaman. Misalnya, menampilkan pesan saat tombol diklik, membuka menu, atau memperbarui isi halaman.

Pilih elemen dengan querySelector, lalu dengarkan kejadian seperti click. Kode di dalam fungsi akan dijalankan ketika tombol ditekan.

  • document.querySelector() mencari elemen.
  • addEventListener() mendengarkan aksi.
  • textContent mengganti teks elemen.
Contoh JavaScript
const tombol = document
  .querySelector("button");

tombol.addEventListener("click", () => {
  tombol.textContent = "Berhasil!";
});
URUTAN KERJANYA
1 Cari tombol → 2 Tunggu klik → 3 Ubah teks
LATIHAN 03

Buat tombol yang bereaksi

Tambahkan aksi klik yang mengganti teks tombol menjadi “Berhasil!”.

Petunjuk

Pilih tombol dengan querySelector lalu ubah textContent di dalam addEventListener.

Contoh jawaban 
const tombol = document.querySelector("button");

tombol.addEventListener("click", () => {
  tombol.textContent = "Berhasil!";
});
